# Spark Fast Loop

`.agents/spark/` is the repo-local fast-loop lane for small, reversible
`abyss-stack` infrastructure corrections. It is an agent overlay inside
`.agents/`, not a root runtime district and not a new owner.

## Current Surfaces

- [AGENTS.md](AGENTS.md): local operating rules for Spark-lane work.
- [SWARM.md](SWARM.md): reusable swarm recipe for one bounded infra seam.

## Contract

Spark work should stay narrow: compose/profile alignment, runbook consistency,
template safety, first-run/doctor/render-truth sync, or one bounded hardening
seam.

It must not redesign runtime topology, widen host exposure, commit secrets, or
claim owner meaning that belongs to sibling AoA or ToS repositories.
