# profiles

`docs/profiles/` owns profile, preset, and recipe selection for the runtime.

| Surface | Role |
|---|---|
| [PROFILES](PROFILES.md) | named profile contracts |
| [PRESETS](PRESETS.md) | preset-to-profile composition |
