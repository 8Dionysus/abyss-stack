# Mechanics Route

The canonical runtime mechanics atlas lives at
[mechanics/README.md](../mechanics/README.md).

Use that tree when the task is about the kind of runtime move being made:
lifecycle, config projection, machine fit, inference pilots, Agon dry-run
runtime, experience seed contracts, federation seams, governed execution,
diagnostics, or repair-safe closeout.

## Current role

This file is a `docs/` entry route. It does not own mechanic doctrine.

The first mechanics wave added first-class package homes under `mechanics/`.
The second wave starts moving noisy flat artifact families into package-local
legacy homes when validators, links, tests, and generated companions move with
them.
