# governance

`docs/governance/` owns repository workflow and integration governance that is
not runtime topology itself.

| Surface | Role |
|---|---|
| [BRANCH_POLICY](BRANCH_POLICY.md) | branch, merge, and retirement route |
| [RELEASING](RELEASING.md) | release flow |
| [QUESTBOOK_STACK_INTEGRATION](QUESTBOOK_STACK_INTEGRATION.md) | questbook integration posture |

Use `docs/decisions/` when future contributors need the rationale for a
structural or workflow choice.
