# operations

`docs/operations/` owns live operation, lifecycle, incident, backup, and
security posture for the deployed AbyssOS runtime.

| Surface | Role |
|---|---|
| [RUNBOOK](RUNBOOK.md) | live triage and operator command routes |
| [LIFECYCLE](LIFECYCLE.md) | lifecycle model and activation status language |
| [BACKUP_RESTORE](BACKUP_RESTORE.md) | backup and restore stance |
| [SECURITY](SECURITY.md) | secret posture and safe defaults |

This district may describe runtime checks, but it must not commit live secrets,
logs, models, or private captures into the source mirror.
