# docs

`docs/` contains repo-wide operator, deployment, lifecycle, storage, security,
release, and decision surfaces for `abyss-stack`.

Mechanic-owned doctrine belongs under `mechanics/<package>/` or a more specific
`mechanics/<package>/parts/<part>/` route. This directory should stay a
repository-level entry layer, not a dumping ground for package-local details.
