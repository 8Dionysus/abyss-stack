# Boundaries

## Owned here

- bounded discovery of `aoa-stats` and inventory-declared local ports
- safe catalog-listed JSON reads
- packet-reader subprocess invocation and error translation
- read-only MCP tool schemas
- stdio and authenticated loopback transport integration

## Owned elsewhere

- statistical grammar, compatibility, identity, aggregation, derived-profile
  meaning, and owner inventory: `aoa-stats`
- local questions, measurements, populations, dimensions, evidence handoffs,
  privacy, and freshness: each owner repository's root `stats/`
- eval verdicts, routing decisions, memory truth, KAG meaning, mechanics
  execution, and runtime mutation: their respective owners
- registration and workspace wrappers: their actual Codex-plane owner

## Stop lines

The service is not a data warehouse, validator runner, evidence collector,
refresh daemon, write API, global score, or proof authority. A successful read
or compatibility result does not strengthen the source it describes.
