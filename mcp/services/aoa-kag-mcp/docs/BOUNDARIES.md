# aoa-kag-mcp Boundaries

## Owns

- MCP server wiring for `aoa-kag` access.
- Read-only resources, tools, prompts, CLI, validation script, and tests.
- Compact runtime-facing packet normalization over the provider map.

## Routes To Owners

| Pressure | Owner |
| --- | --- |
| KAG schema and provider validation | `aoa-kag` |
| Authored meaning in a repo | that repo's source surfaces |
| Direct repo provider records | that repo's `kag/` home |
| Runtime graph/vector/cache state | runtime owner in `abyss-stack` or `.aoa` |
| Reviewed proof, memory, routing, role, skill, technique, playbook meaning | owning AoA organ repo |

## Access Rule

MCP packets are navigation and inspection aids. Source-return routes remain the
stronger route for meaning changes.
