# ToS Corpus MCP Boundaries

- Tree of Sophia owns `ToS/` resources, `tos_corpus_index.min.json`, and
  `philosophy_graph_projection.min.json`.
- `abyss-stack` owns this MCP access plane and any runtime projection or UI
  that consumes those exports.
- MCP packets are navigation aids, not source truth.
- Neo4j, graph UI, and MCP resources must stay projection-only.
- This package has no writeback route.
