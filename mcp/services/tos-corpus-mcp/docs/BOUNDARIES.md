# ToS Corpus MCP Boundaries

- Tree of Sophia owns `ToS/` resources, `tos_corpus_index.min.json`, and
  `philosophy_graph_projection.min.json`.
- `abyss-stack` owns this MCP access plane and any runtime projection or UI
  that consumes those exports.
- MCP packets are navigation aids, not source truth.
- Neo4j, graph UI, and MCP resources must stay projection-only.
- This package has no writeback route.
- The read bearer is owner-specific and cannot be reused for another organ.
- Tool annotations reflect the proven read contour; they do not replace the
  filesystem-read-only process boundary or behavior tests.
- Source readiness, a staged credential, bundle membership, a running process,
  a consumer registration, and a grounded result are distinct states.
- Until the deployed workspace wrapper and live canary exist, `tos-corpus`
  remains a registry shadow and outside the default owner bundle.
