# Federation Seams Parts

Federation-seams parts keep runtime consumption of sibling owner surfaces
explicit. These routes are advisory and do not absorb sibling authority.

The sync-wrapper part also owns the reversible SDK routing-canary intake. That
adapter may prove `canary_ready`; it cannot make the SDK producer canonical or
satisfy ordinary runtime closure.
