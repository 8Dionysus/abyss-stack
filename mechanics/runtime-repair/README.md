# Runtime Repair Mechanic

## Mechanic card

Runtime repair is the mechanic for bounded degradation evidence, repair-safe
closeout, A2A return dry-run, chaos-wave recovery posture, and antifragility
contracts.

### Trigger

Use this package when changing service degradation receipts, repair-safe
closeout receipts, chaos-wave runtime docs, A2A return closeout dry-run,
contradiction integrity runners, or antifragility runtime posture.

### abyss-stack owns

- runtime-side degradation and closeout receipt contracts
- repair-safe closeout docs and examples
- dry-run return adapters
- runtime recovery evidence boundaries
- public-safe antifragility posture

### Stronger owner split

Actual repair workflows belong to operator action, `aoa-skills`, and affected
owner repositories. `abyss-stack` can expose evidence and bounded dry-runs; it
does not author final proof, memory truth, or owner remediation.

### Inputs

Diagnostic outputs, runtime logs, degradation observations, advisory owner
refs, explicit operator intent, and public-safe examples.

### Outputs

Degradation receipts, repair-safe closeout receipts, return dry-run packets,
handoff candidates, and recovery posture docs.

### Must not claim

- receipt equals repair
- dry-run equals live return
- degradation evidence proves root cause
- runtime can fix owner-owned doctrine
