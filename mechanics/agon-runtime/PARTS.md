# Agon Runtime Parts

| Part | Current source surfaces |
|---|---|
| Active route | `README.md`, `DIRECTION.md`, `PROVENANCE.md` |
| Old source docs | `legacy/raw/AGON_*` |
| Config seeds | `legacy/artifacts/config/agon_*.seed.json` |
| Generated registries | `legacy/artifacts/generated/agon_*.min.json` |
| Event examples | `legacy/artifacts/examples/agon_*` |
| Runtime scripts | `legacy/artifacts/scripts/*agon*` |
| Contract schemas | `legacy/artifacts/schemas/agon-*.schema.json` |
| Tests | `legacy/artifacts/tests/test_agon_*` |
| Recurrence evidence | `legacy/artifacts/manifests/recurrence/` |

Legacy file names are intentionally preserved for provenance. New active files
should receive quieter package-local names when they graduate out of `legacy`.
