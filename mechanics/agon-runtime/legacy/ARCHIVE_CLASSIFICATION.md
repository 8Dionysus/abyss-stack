# Agon Runtime Archive Classification

This file classifies preserved Agon runtime legacy material without promoting
old wave-shaped source pressure into active `abyss-stack` topology.

## Verdict

The raw Agon runtime documents and old `ABS-Q-AGON-*` quest stubs remain
provenance-only.

The runnable dry-run substrate has already been distilled into
`../parts/runtime-kernels/`. The old raw documents still explain lineage, but no
active service, operator command, validator, or runtime state should consume
them as current law. Agon verdict meaning, rank, scar, retention, KAG, and Tree
of Sophia promotion remain stronger-owner concerns outside `abyss-stack`.

## Families

| Family | Legacy home | Current verdict |
|---|---|---|
| Duel runtime kernel docs | `raw/AGON_DUEL_RUNTIME_KERNEL.md`, `raw/AGON_DUEL_RUNTIME_STOP_LINES.md`, `raw/AGON_DUEL_EVENT_LOG_MODEL.md` | lineage for `parts/runtime-kernels/`; not active law |
| Mechanical trial docs | `raw/AGON_MECHANICAL_TRIAL_RUNTIME.md`, `raw/AGON_MECHANICAL_TRIAL_EVENT_LOGS.md` | lineage for mechanical trial examples and registries; not a live trial authority |
| Landing and stop-line notes | `raw/AGON_WAVE12_RUNTIME_LANDING.md`, `raw/AGON_WAVE13_RUNTIME_LANDING.md`, `raw/AGON_WAVE13_RUNTIME_STOP_LINES.md` | preserved source pressure only; old wave names stay here |
| Quest stubs | `raw/quests/ABS-Q-AGON-*.md` | historical quest pressure; not root questbook source and not active `abyss-stack` obligations |
| Old technical artifacts | `artifacts/README.md` | marker-only; active artifacts live under `../parts/runtime-kernels/` |

## Promotion Gate

Promote only a bounded slice, and only when all of these are true:

- the active consumer is an `abyss-stack` runtime command, definition, schema,
  example, generated registry, simulation, or test under `parts/runtime-kernels/`
- active names avoid old wave, seed, or flat artifact topology
- the stronger owner split is stated before runtime adoption
- validators and tests move with the promoted artifact
- `INDEX.md`, `DISTILLATION_LOG.md`, and this classification keep the lineage
  link clear

Until then, `legacy/raw/` and `legacy/artifacts/` are the correct homes.
