# Agon Runtime Mechanic

## Mechanic card

Agon runtime is the `abyss-stack` mechanic for bounded local dry-run support
around Agon duel kernels, mechanical trial event logs, and generated runtime
registries.

### Trigger

Use this package when changing local Agon runtime kernels, dry-run event logs,
trial-run registries, or runtime validation scripts.

### abyss-stack owns

- local event-log validation and generated registry checks
- runtime-only examples that prove dry-run behavior remains bounded
- package-local definitions, scripts, schemas, examples, and tests that keep
  the Agon runtime kernel substrate green
- archive lineage from old flat artifact names into the current mechanics tree

### Stronger owner split

`Agents-of-Abyss` owns Agon doctrine, law, playbook meaning, rank, scar,
retention, and verdict semantics. `aoa-sdk` owns portable integration helpers
when Agon surfaces need SDK bindings. `abyss-stack` only owns the local runtime
substrate and dry-run proof shape.

### Inputs

Archived Agon source docs plus active runtime-kernel definitions, generated
registry capsules, event-log examples, runtime validators, tests, and recurrence
observation manifests under `parts/runtime-kernels/`.

### Outputs

Dry-run registries, validation results, runnable local simulations, and
package-local provenance that points back to stronger owner surfaces.

### Must not claim

- live verdict authority
- durable scar, rank, or retention mutation
- Tree of Sophia or KAG promotion rights
- background service activation
- that an archived raw file is the active package route
