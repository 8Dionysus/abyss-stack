# Inference Pilots Direction

The current contour keeps local inference trial-backed and promotion-aware.

Short term:

- keep llama.cpp and Qwen pilot routes explicit
- keep LangGraph adoption bounded to local-worker flows
- keep benchmark and trial evidence public-safe unless explicitly private
- run the Tree of Sophia foundation suite no-download-first, preserving manual
  review authority and one-candidate-at-a-time admission

Next movement should separate stable pilot cards from pilot-specific trial
records without losing validator coverage.

The ToS foundation laboratory is a bounded domain suite inside this mechanic,
not a second runtime owner. It consumes machine-fit and host policy, and it
returns only reviewed derivative candidates to Tree of Sophia.
